# 独自ドキュメント対応チャットボット (RAG)

Streamlit と LangChain を活用して構築された、OpenAI互換API汎用対応のPDFドキュメント対応RAG（Retrieval-Augmented Generation）アプリケーションです。複数のPDFファイルを同時にアップロードしてローカルのベクトルデータベースに永続化し、最新のUI/UXと高度な詳細設定を通じてドキュメントに基づいた対話を行うことができます。

---

## 🚀 アップグレードされた機能・特徴

### 1. UI/UXの洗練（プレミアムデザイン）
- **モダンな高級感あるテーマ**: Google Fonts（Outfit, Inter）を導入し、Indigo-Cyan-Blueの美しい線形グラデーションヘッダーを採用。
- **スライドアニメーション**: 新しいチャットメッセージが表示される際に、下から滑らかに浮かび上がるスライドアニメーションを適用。
- **参照元の折りたたみ表示 (`st.expander`)**: 回答の元になったドキュメント名とページ番号を、メッセージ最下部のアコーディオンに隠してすっきり表示。過去の会話履歴でもアコーディオン状態が維持されます。
- **会話クリアボタン**: メイン画面のヘッダータイトル右隣に「🗑️ 会話クリア」ボタンを配置し、ワンクリックで履歴を初期状態にリセット可能。

### 2. マルチドキュメント対応 & ローカル永続化
- **複数ファイルの同時アップロード**: 複数のPDFを一括選択して一降でインデックス化し、まとめて検索対象にできます。
- **インデックス管理と個別削除**: アップロードされたファイル名がサイドバーに一覧表示され、不要なドキュメントは 🗑️ ボタンで個別にベクトルDBから削除できます。
- **Chromaのローカル永続化**: インデックス化されたデータは `./chroma_db` ディレクトリに自動保存され、アプリを再起動しても前回のデータを再ロードして即座に使用できます。

### 3. OpenAI互換APIへの汎用対応
- **Base URLのカスタマイズ**: 接続先のAPIアドレスを任意に設定でき、LM Studio, Ollama, vLLM, LiteLLM, DeepSeekなどのOpenAI互換APIへ接続可能です。
- **モデル一覧の動的取得**: 指定された接続先から `/v1/models` エンドポイント経由で利用可能なモデル一覧を動的取得し、プルダウンメニューで選択できます（取得失敗時はOpenAI標準モデルへ自動フォールバック）。
- **カスタムモデル名の手動入力トグル**: エンドポイントがモデル一覧取得に対応していない場合でも、チェックを入れて自由なモデル名をタイピングできます。
- **カスタム埋め込みモデル名指定**: 接続先のローカルモデルに合わせた埋め込みモデル名（デフォルトは `text-embedding-3-small`）を指定できます。

### 4. RAG調整（詳細設定）& 統計情報
- **統計情報のカード表示**: インデックス化された資料全体の「総ページ数」と「総チャンク数」をスタイリッシュなメトリクスカードでリアルタイム可視化。
- **チャンクサイズ & 重複サイズ調整**: スライダー（チャンクサイズ: 100〜3000、重複サイズ: 0〜500）で、PDF分割時のブロック粒度を最適化可能。
- **検索アルゴリズム調整**: 通常の類似度検索（`similarity`）に加え、結果の多様性を高め重複回答を防ぐ `mmr` (Maximum Marginal Relevance) を選択可能。
- **取得ドキュメント数（k）調整**: 質問時に参照させるチャンク数を 1〜10 のスライダーで動的変更可能。

### 5. プロンプトモード切替（回答方針）
- **厳格に文書回答（ハルシネーション抑制）**: 与えられたドキュメントの文脈のみに基づいて回答し、書かれていない質問には「提示されたドキュメントからは分かりませんでした」と誠実に応答します。
- **一般知識も交える（ハイブリッド）**: ドキュメントの内容を最優先としつつ、不足している情報はLLM自身の一般知識で補完して回答します（その際、「※提示されたドキュメント以外の知識に基づきます」との補足が自動挿入されます）。

## 🛠️ 必須環境・インストール

### 必須環境
- Python 3.10以上
- OpenAI API Key または OpenAI互換APIの接続環境

### インストール方法
必要なライブラリおよび環境変数管理パッケージをインストールします。
```bash
pip install streamlit langchain langchain-openai langchain-chroma langchain-community langchain-classic pypdf python-dotenv openai
```

---

## ⚙️ 使い方

1. **環境変数の設定 (オプション)**:
   プロジェクトのルートディレクトリに `.env` ファイルを作成し、以下のように定義しておくと起動時に自動反映されます。
   ```env
   OPENAI_API_KEY=your-openai-api-key
   OPENAI_API_BASE=https://api.openai.com/v1
   ```

2. **アプリケーションの起動**:
   Windows環境ではプロジェクトフォルダ内の `run.bat` をダブルクリックするか、以下のコマンドを実行します。
   ```bash
   streamlit run app.py
   ```

3. **Web UIでの設定**:
   - **設定**: 左側のサイドバーでAPIキーと接続先Base URLを確認（変更があれば入力）します。
   - **RAG設定/回答モード**: 必要に応じて「詳細RAG設定」スライダーや「回答モード」ラジオボタンを調整します。
   - **ドキュメントのアップロード**: PDFファイルをドラッグ＆ドロップし、「インデックス作成」をクリックします。
   - **チャット開始**: 右側のメインエリアのチャット入力欄から質問を入力します。
